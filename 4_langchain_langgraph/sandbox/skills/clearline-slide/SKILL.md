# Clearline Advisory recommendation slide

## When to use

Use this skill when a briefing or comparison ends in a recommendation and someone asks for a slide. The deliverable is always a single slide, never a full deck.

## House style

- The title states the decision as a direct action, for example "Standardize the fleet on Tesla Model Y"; under 40 characters, no hedging and no "For X, do Y" framing
- Exactly three key points, each one line, and each one must include a concrete number (a price, a percentage, a range, a count) — a point with no number is not specific enough to keep
- The recommendation is one sentence that states the decision, an explicit next step, and a timeframe, for example "Approve Model Y for the first 25-vehicle order this quarter; revisit Mach-E only if Ford sourcing becomes a requirement." A recommendation with no next step or no timeframe is not approvable as stated
- Plain, declarative, active voice. Cut hedging words: "could", "might", "perhaps", "may want to"
- Layout is applied automatically by the create_slide tool, so focus on the words and let the tool handle the design

## Workflow

1. Read the briefing or comparison you have been given
2. Distill the three key points, each with a number attached
3. Write the one-sentence recommendation with a decision, a next step, and a timeframe
4. Call the create_slide tool with the title, key points and recommendation
